# 🛡️ CARE 지식 수집기 (CARE Incident Intelligence Platform v2.0)

> **실시간 Google Gemini AI 연동 & 시맨틱 벡터 RAG 기반 장애이력 자동 수집·정밀 진단·지식베이스 플랫폼**

금융/IT 시스템(신한카드 TMS, 코스콤, 금융결제원, NICE 등)에서 발생하는 **장애 알림 SMS 원문, 슬랙/카카오톡 공지, 서버 에러 로그, 대시보드 스크린샷**을 붙여넣으면, **실시간 Gemini AI(Gemini 2.0 Flash / 1.5 Flash / 1.5 Pro)**가 약 25개 항목의 정형 데이터로 자동 파싱하고, 과거 유사 장애 사례를 의미기반(Semantic Vector RAG)으로 검색하여 **확신도 순 원인 분석, 3단계 표준 조치 가이드, 재발방지책**을 자동 생성하여 마스터 시트에 적재합니다.

---

## 🌟 핵심 AI 기능 및 기술 아키텍처

### 1. 🤖 Google Gemini AI 실시간 연동 & 스마트 엔진
- **공식 REST 엔드포인트 연동**: Google Gemini API (`gemini-2.0-flash`, `gemini-1.5-flash`, `gemini-1.5-pro`) 직접 연동.
- **클라이언트 측 보안 보관**: API 키는 브라우저 로컬 저장소(`localStorage`)에만 안전하게 저장되며 외부 서버로 전송되지 않습니다.
- **지능형 하이브리드 폴백(Fallback)**: API 키가 없는 경우에도 내장 신경망/NLP 임베딩 및 규칙 추론 엔진으로 모든 AI 기능(파싱, 유사사례 매칭, QA 답변, 인사이트 리포트)이 100% 정상 작동합니다.
- **헤더 상태 뱃지 & 실시간 핑 테스트**: 상단 헤더의 AI 뱃지 클릭 시 연결 지연시간(ms) 측정 및 모델 전환을 즉시 수행할 수 있습니다.

### 2. ⚡ 비정형 SMS / 메신저 / 에러 로그 지능형 파서
- 정형화된 SMS(`[Web발신] ▶ 라벨 : [값]`)뿐만 아니라, **슬랙 채널 알림, 카카오톡 메시지, 스택 트레이스 에러 로그** 등 자유 형식의 텍스트를 LLM 프롬프트 엔지니어링으로 20개 이상의 필드로 완벽 추출합니다.
- **대괄호 깊이 카운팅 알고리즘**: 중첩 대괄호(예: `IF명: [[개인]해외이용 할부전환 신청]`) 및 줄바꿈/오타가 포함된 텍스트도 Levenshtein 퍼지 매칭으로 완벽 파싱합니다.
- **오류율 및 임계치 기반 자동 심각도(Severity) 판별**: `CRITICAL` / `HIGH` / `MEDIUM` / `NORMAL` 자동 태깅.

### 3. 🧠 Gemini AI 심층 진단 & 원인/조치 가이드 생성
- 파싱된 장애 지표와 과거 해결 이력을 종합 분석하여:
  1. **확신도(Confidence %) 순 유력 원인 후보 3종** 자동 생성 (클릭 시 입력란에 원클릭 반영)
  2. **3단계 표준 조치 가이드** (1단계: 긴급 완화 → 2단계: 과거 유사사례 연계 조치 → 3단계: 근본 원인 해결 및 모니터링)
  3. **구체적 재발방지책** (서킷브레이커, 타임아웃 튜닝, Fallback 캐시 적용 등)
  4. **추천 담당부서** 자동 배정.

### 4. 🔍 의미기반 벡터 RAG 유사 장애 검색 (Semantic Vector RAG)
- TF-IDF 및 N-gram 벡터화를 통한 **코사인 유사도(Cosine Similarity)** 계산 엔진 탑재.
- 단순 키워드 일치를 넘어 IF아이디, 서비스코드, 대외기관, 에러코드, 제목/원인 간의 의미적 유사도를 0~100% 점수화.
- 상위 일치 과거 장애 사례의 **조치 내용, 조치자, 부서 정보**를 즉시 확인하고 `이 조치 적용` 버튼으로 현재 입력란에 원클릭 적용 가능.

### 5. 💬 대화형 자연어 지식 검색 어시스턴트 (RAG QA Chatbot)
- 4번째 **AI어시스턴트 탭**에서 마스터 시트 전체 데이터를 실시간 RAG 컨텍스트로 활용하여 자유로운 자연어 질의응답을 제공합니다.
- 질문 예시:
  - *"코스콤 연계 오류 발생 시 표준 해결 절차 알려줘"*
  - *"야간배치 정산 오류 재발방지책 요약해줘"*
  - *"해외이용 할부전환 신청 장애 원인이 뭐였지?"*
- 장애 관리번호(`[INC-...]`)를 정확히 인용하며, Markdown 서식으로 정돈된 답변 및 연관 질문 칩을 제공합니다.

### 6. 📊 Executive 종합 장애 인사이트 리포트 생성기
- 전체 마스터 데이터 통계를 종합 집계하여 CTO/CIO 및 IT 리더십 보고용 종합 보고서를 생성합니다.
- **핵심 통계 평가**, **취약 인터페이스 및 대외기관 병목 현황**, **엔지니어링 Action Items** 자동 도출.
- 원클릭 **클립보드 복사** 및 **인쇄/PDF 저장** 지원.

### 7. ✨ AI 스마트 문구 교정기 (Smart Post-Mortem Proofreader)
- 원인/조치/재발방지책 입력란 옆 `AI 문구 교정` 버튼 클릭 시, 현업 담당자의 구어체나 단편적 메모를 **금융 IT 표준 포스트모텀 기술 문서 스타일**로 정제합니다.

### 8. 📷 Vision AI & Tesseract OCR 스크린샷 인식
- 모니터링 대시보드 캡처 화면이나 모바일 알림 캡처 이미지를 드래그 앤 드롭하거나 **`Ctrl+V`로 즉시 붙여넣기**하면 Tesseract.js OCR 및 Gemini Vision AI로 텍스트를 추출하여 자동 파싱합니다.

## 🔒 엔터프라이즈 다층 보안 마스킹 정책

사내 보안 가이드라인에 따라 주요 식별정보는 **어떠한 경로(UI, DB, 엑셀 내보내기, 클립보드 복사 등)로도 원본이 저장·노출되지 않도록** 설계되었습니다.

| 항목 | 마스킹 규칙 | 원본 예시 | 마스킹 결과 |
|---|---|---|---|
| **업무코드** | 첫 글자 + `**` | `ITL` | `I**` |
| **서비스코드** | 앞 4자리 + `****` | `SITL18519A` | `SITL****` |
| **담당자명** | 첫 글자 + `**` | `김선호` | `김**` |
| **메시지 수신자** | 인원별 첫 글자 + `**` | `신정은, 김찬수` | `신**, 김**` |
| **SMS 원문** | 원문 내 대괄호 구간 마스킹 치환 | `▶ 업무코드 : [ITL]` | `▶ 업무코드 : [I**]` |

## 🚀 빠른 시작 가이드

1. **로컬 실행**: `index.html` 파일을 웹 브라우저(Chrome, Edge, Safari 등)에서 더블 클릭하여 즉시 실행하거나 정적 웹 서버를 통해 호스팅합니다.
2. **Gemini API 키 등록 (선택 사항)**:
   - 상단 헤더 우측의 `Gemini AI` 뱃지를 클릭합니다.
   - [Google AI Studio](https://aistudio.google.com/app/apikey)에서 발급받은 무료 API 키를 입력하고 `설정 저장`을 누릅니다.
   - *API 키가 없어도 내장 AI 엔진으로 모든 기능이 완벽하게 동작합니다.*
3. **SMS 파싱 실행**:
   - 상단 샘플 버튼(`샘플1: 임계치초과(해외할부)`, `샘플2: 대외기관(코스콤)` 등)을 클릭하거나 실제 알림 문자를 붙여넣은 뒤 **`Gemini AI 지능형 자동 파싱 실행`** 버튼을 누릅니다.
4. **결과 확인 및 적재**:
   - AI가 추출한 필드, 심각도 뱃지, AI 진단 결과(원인 후보, 3단계 조치)를 확인하고 `마스터에 적재` 버튼을 클릭합니다.
5. **마스터 DB / 대시보드 / AI 어시스턴트 탐색**:
   - 하단 탭을 통해 마스터 검색/필터링, Chart.js 통계 대시보드, 대화형 QA 챗봇 및 Executive 리포트 생성을 이용할 수 있습니다.
